5. Umestacionamento possui a seguinte regra: Um veículo pode entrar se o
motorista possuir carteira de habilitação e o veículo estiver licenciado. Con
sidere que você possui apenas as variáveis habilitado e licenciado.
A primeira sugestão foi utilizar seguinte condição para negar a entrada:
!(habilitado && licenciado). Reescreva a expressão anterior sem
utilizar os parênteses e mantendo o mesmo significado lógico.

#include <stdio.h>

int main() {
    int habilitado, licenciado;
    
    if (!(habilitado && licenciado) == (!habilitado && !licenciado)) {
        return 1;
    }
}
OUTPUT: 1

idade >= 20 && idade < 50. Escreva uma expressão lógica equivalente que represente quando a entrada deve ser negada. Não utilize apenas a expressão acima diretamente negada.
