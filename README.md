✨ Sobre o repositório

Este repositório reúne minhas anotações e materiais de estudo das aulas de 2026 do curso de Análise e Desenvolvimento de Sistemas (ADS), na FATEC de Campinas.

A ideia é manter o conhecimento organizado, registrar os principais conceitos aprendidos em sala de aula e construir uma base de consulta para revisões, atividades e estudos futuros.

💡 Aprender é o primeiro passo. Registrar, organizar e revisar é o que transforma informação em conhecimento.
🎯 Objetivo
📖 Registrar os conteúdos apresentados nas aulas.
🧠 Facilitar a revisão dos conceitos estudados.
🗂️ Organizar o conhecimento em um único lugar.
🚀 Acompanhar minha evolução acadêmica ao longo do curso.
💻 Construir uma base de conhecimento que possa ser consultada no futuro.

As anotações serão organizadas conforme as disciplinas e os assuntos abordados durante o semestre.
